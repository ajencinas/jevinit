What this comparison can't show

  • Which model is more accurate or faster in general. This is one incident and one call each.
  • A like-for-like workload. The chat model answered 5 fields and Jev 12, so token counts and times measure different jobs.
  • How often a chat reply fails to parse. Strict JSON-schema mode makes that rare.
  • That Jev's reply needs no handling. It is JSON as well, parsed by zeroops/schema.py; a missing or malformed answer now sends the incident to a person.
  • Whether Jev's probabilities can be trusted as stated. On our 56 incidents that is mixed; see the calibration chart in the Threshold Lab.
